# BM Free Music v1.1.0

## 这次更新

**新图标** — 换成 BM Free—music 的正式标识。

**动画** — 页面切换淡入上移，列表逐行错峰入场，磁贴依次浮现，切歌时封面弹入。系统开了「减少动态效果」会自动关掉。

**搜索提速** — 不再等九个源全部返回。网易云和 QQ 的结果先到先显示，其余音源的结果到了自动合并进来。

**自动播放修复** — 部分机型上点歌提示「播放被拦截」。现在会记住这个状态，你随手点一下页面任何地方（不只是播放按钮）就会自动续上。

**歌手简介** — 曲目菜单和播放页的歌手名都能点。优先查维基百科，中文词条没有再试英文；国内网络访问不了维基时自动退到百度百科，带结构化字段（本名、外文名、出生日期、国籍等）。

**下载** — 曲目菜单新增「下载到本地」。解析出直链后交给系统 DownloadManager，文件落在手机的 Music 目录，通知栏能看到进度。网页版走浏览器下载。

**音源设置可滑动** — 九个音源的按钮改成横向滚动，不再折行挤成一团。

**文案收敛** — 去掉了一批解释性的说明文字。

## 安装

`BMFreeMusic-1.1.0.apk` · 0.57 MB · Android 6.0+

比上一版小了近一兆，因为图标换成矢量风格的简洁图，不再是那张大照片。

覆盖安装即可，签名没变，数据不会丢。

## 校验

```bash
sha256sum -c SHA256SUMS.txt
```

## 已知限制

- **维基百科在部分网络下不可达**，这时简介会显示百度百科的内容，来源标注在卡片底部。
- 酷我音源的部分曲目拿不到封面，显示占位图。
- B 站搜索接口偶尔返回 `-412 banned`，属于上游风控。
